# Pipeline per shot

Generated by `shots/build_shots.py` from the brief's shot list (doc rev 54) and `timing/timing_map.json`. Do not edit by hand; edit the script.

**Pipelines.** Blender 5.2 (Python, Eevee) renders 3D plates (`scenes/blender/plates.py`). One HTML page (`overlays/video.html`) renders every JS layer for any frame and is captured by Puppeteer (`scripts/render_frames.mjs`) as transparent PNGs. An assembly step maps each frame to its plate (rendered, held for freezes, or split for S19), and ffmpeg composites and muxes the audio. Every frame is a pure function of (t, seed) (step 4).

**Global layers** run over every shot except S23: `captions` (word-timed lyrics, style spec; large in the 2D shots) and `chrome` (credit with version, seed label, FPS counter).

**Framing.** 3D plates are rendered 20% wider than 16:9 so the 9:16 crop for the vertical cut (S14-S22) can reframe without re-rendering. JS layers are laid out per aspect ratio.
