# Pipeline per shot (v3)

Generated by `shots/build_shots.py` from the brief's v3 shot list and `timing/timing_map.json`. Do not edit by hand; edit the script.

**Pipelines.** Blender 5.2 (Python, Eevee) renders 3D plates (`scenes/blender/plates.py`): each plate is a scene with named cameras and effects. One HTML page (`overlays/video.html`) renders every JS layer for any frame, captured by Puppeteer. `scripts/assemble.py` builds each frame's plate (rendered, held, or an N-up split), applies Chorus 2's degradation, composites the overlay, applies whip and glitch transitions, and pipes raw frames to ffmpeg with the audio. Every frame is a pure function of (t, seed).

**Cutting.** Cuts land on the downbeat nearest the anchor if it is within a quarter bar, otherwise 0.1 s before it, so no cut falls mid-word.
